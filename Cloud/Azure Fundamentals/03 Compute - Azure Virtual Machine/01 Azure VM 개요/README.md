# 03 Compute - Azure Virtual Machine / 01 Azure VM 개요

Azure VM을 만들기 전에 그 정체를 잡는 이론 섹션. 콘솔에서 "VM 하나"로 보이는 것이 사실은 여러 리소스의 조합임을 이해하고, 크기·이미지·디스크 선택의 기준을 잡는다.

## What you will learn

- VM은 하나가 아니다: Compute·OS Disk·NIC·Public IP·NSG의 조합, "Create VM"이 숨기는 구조
- 구성 요소 각각의 역할
- Size 패밀리(B·D·E·F)와 세대: 무엇을 결정하나
- 이미지(Gen2)와 디스크 타입(Standard·Premium·Ultra) 개요
