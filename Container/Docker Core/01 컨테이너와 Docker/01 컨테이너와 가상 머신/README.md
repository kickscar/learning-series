# 01 컨테이너와 Docker / 01 컨테이너와 가상 머신

컨테이너가 해결하는 문제와 가상 머신과의 차이를 정리한다. 이미지와 컨테이너의 관계를 정의하고 컨테이너가 적합하지 않은 경우를 함께 제시한다.

## What you will learn

- 실행 환경의 차이로 발생하는 문제와 컨테이너 이미지를 이용한 해결
- 호스트 커널 공유에서 발생하는 가상 머신과 컨테이너의 차이
- 가상 머신과 컨테이너의 병용 구성
- 이미지와 컨테이너의 관계
- 가상 머신을 선택해야 하는 워크로드의 조건
