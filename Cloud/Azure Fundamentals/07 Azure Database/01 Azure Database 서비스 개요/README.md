# 07 Azure Database / 01 Azure Database 서비스 개요

## What you will learn

- 관리형 DB — 프로비저닝·패치·백업·HA를 Azure가, 앱은 연결만

- Flexible vs Single Server — Single 은퇴(2024-09), **Flexible만 현행**(VNet 통합·stop/start·Zone 이중화)
- AWS 대응 — RDS(엔진 묶음) vs Azure(엔진별 서비스)
