# 09 Container - ACR & Azure Container Apps / 01 컨테이너와 Azure 컨테이너 서비스 개요

컨테이너 기초와 Azure 컨테이너 서비스(ACI/Container Apps/AKS) 지형을 이해하고, 순수 인프라 → Cloud Native 전환 위치를 잡는 이론 섹션.

## What you will learn

- 컨테이너 기초 — 이미지(불변 패키지) / 컨테이너(실행) / 레지스트리
- VM vs 컨테이너 — OS 가상화 vs 커널 공유·프로세스 격리
- Azure 지형 — ACI(단일) / Container Apps(서버리스, scale-to-zero) / AKS(완전 K8s), 관리 위임 스펙트럼
- AWS 대응 — ACR↔ECR, Container Apps↔Fargate/App Runner, AKS↔EKS
- 시리즈 경계 — 관리형 컨테이너까지, 오케스트레이션은 별도
