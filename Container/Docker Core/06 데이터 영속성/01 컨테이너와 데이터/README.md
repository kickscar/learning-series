# 06 데이터 영속성 / 01 컨테이너와 데이터

컨테이너를 교체할 때 데이터가 사라지는 상황을 정리하고, 데이터를 컨테이너 밖에 두는 세 가지 저장 방식과 용도별 선택 기준을 다룬다. 파일과 데이터베이스의 소실을 재현하고, 볼륨을 연결한 같은 절차에서 데이터가 유지되는 것과 대조한다.

## What you will learn

- 이미지 교체 배포, 실행 설정 변경, 장애 후 재생성에 따른 컨테이너 교체와 쓰기 레이어 데이터의 소실
- 볼륨, 바인드 마운트, tmpfs의 관리 주체, 위치, 수명과 용도별 선택
- 이미지가 선언한 볼륨 경로(`mariadb:11` 의 `/var/lib/mysql`)와 교체 시 새로 연결되는 익명 볼륨
- `--mount type=volume` 으로 연결한 볼륨의 교체 후 데이터 유지
- 컨테이너 삭제와 볼륨 삭제(`docker volume rm`)의 분리

## Examples

- `lab01` → 데이터 소실 재현 (파일과 데이터베이스 소실, 볼륨을 연결한 교체, 컨테이너 삭제와 볼륨 삭제)
