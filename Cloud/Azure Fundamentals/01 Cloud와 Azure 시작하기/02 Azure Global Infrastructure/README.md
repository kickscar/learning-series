# 01 Cloud와 Azure 시작하기 / 02 Azure Global Infrastructure

- Resource 배치 전략: 단일 AZ / AZ 분산 / Region Pair (와 AZ 우선 흐름)
- Geography(데이터 거주지 경계)와 Sovereign Region
