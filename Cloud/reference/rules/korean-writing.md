# Rule: korean-writing

한국어 문서 작성 규칙.

---

## 기본 원칙

- 문서는 **한국어**로 작성
- 기술 용어는 **영문 유지** — 번역하지 않음
- 문체: **~다 체** (서술형)

---

## 서술 톤 — 격식·리터럴·정확 (최우선)

학습자용 문서는 **격식 있는 기술 문서**다. 목표는 사실을 정확하고 명료하게 전달하는 것이며, 친절함은 *쉬운 설명*으로 얻지 비유·구어·친근한 호칭으로 얻지 않는다. writer는 작성 중 점검하고, **reviewer는 아래 위반을 검토 항목으로 확인한다.**

**판별 기준**: 이것이 *Azure·네트워크의 사실 서술*인가, 아니면 *글쓴이의 수사(비유·서사·친근함)*인가. 후자면 걷어낸다.

### 1) 레지스터 (격식)
| 지양 | 지향 |
|------|------|
| 현장 구어·반말투 (앱은 **도는데**) | 격식체 (앱은 **실행되지만**) |
| **2인칭 독자 호칭** (네/너/당신, "**네** 설계") | 무인칭 ("**설계한 부분**"), 필요시 "사용자" |
| 구어 축약 (게/건/걸/이건/땐) | 것이/것은/것을/이것은/때는 |
| **화자·내레이션** ("질문을 **남긴다**", "**짚어보자**", "**되짚는다**") | 사실 서술 ("과제를 확인한다", "다시 본다") |
| ~하십시오/해주세요/할 수 있습니다/클릭합니다 | ~한다 체 (콘솔 경로+이미지로 대체) |

### 2) 리터럴 (사실 서술, 은유 금지)
| 유형 | 지양 | 지향 |
|------|------|------|
| **의인화**(트래픽·자원) | NAT를 **탄다** · 8080에 **닿는다** · 앱이 **올라와 있다** · **못 들어온다** | **경유한다** · **도달한다** · **배포되어 있다** · **차단된다** |
| **문학적 비유** | **문 앞에 길** · 구멍을 **뚫는다** · **정문/옆문** · **피날레** · **뜯는다** · **이정표** · **배관** · 리소스를 **세운다** | **경로가 없다** · 포트를 **연다** · **통제된 경로** · 마지막 실습 · **분리한다** · **설정 정보** · **구성** · 리소스를 **만든다** |
| **동사 정밀**(생성·배포) | 리소스를 **배포한다** · 리소스를 **세운다** | 리소스는 **만든다**(create) · 앱은 **배포한다**(deploy) |
| **생활 구어** | **아까울 게 없다** · **깨끗한 상태** · **통째로** · **손으로** · **눈으로** · **덕에** · **총동원** | 유지하지 않는다 · 빈 상태 · 전체가 · **직접** · **직접 확인** · ~하여 · 적용 |
| **기획·서사 은유**(우리 작업 언어) | **회수한다** · **거둔다** · **씨앗/밑밥** · **관통** · **약속** · **되돌아온다** | 정리한다 · 다시 다룬다 · 핵심 개념 · **의도** · 다시 다뤄진다 |

> **동사 정밀 보충**: 이 시리즈는 **콘솔(포털 클릭) 기반**이라 리소스는 **만든다**(포털 "만들기")가 리터럴이다. **배포**는 앱/코드를 올리거나 IaC의 apply(인프라를 코드로 배포) 뉘앙스라 콘솔 리소스 생성에 쓰지 않는다 — 단 **앱**(Gallery)을 올리는 것은 **배포**가 맞다("골든이미지로 배포", "직접 배포한 pet"). '세운다'(erect)는 비유라 어느 경우든 지양.

### 3) 정확성
- **다의어·모호어 금지** → 하나의 의미만 있는 단어. ("**쌓았다**"[스택? 지식?] → "**차례로 다뤘다**")
- **추상 지칭 금지** → 구체. ("**빈 자리**" → "아직 없는 흐름")
- **미도입 개념 forward-reference 금지** → 뒤 챕터에서 처음 도입되는 용어(예: 골든 이미지)를 앞 섹션에서 끌어오지 않는다.

### 4) 허용 (오해 방지)
- **표준 기술 용어**: `잠근다`(lock down)·SNAT·라우팅·필터링 등 업계 표준어.
- **인용된 실제 FAQ·에러**: `"Public IP가 있는데 왜 접속이 안 되나"` 같은 사용자 질문 재현.
- **의도된 구조 analogy**: 온프렘 물리 디스크 비유 등 (수사가 아니라 *구조를 설명*하면 허용).

### 5) 맥락·thread는 주장하지 않는다 — 구조로 실현한다
관통 개념(subnet=정책 스코프 등)·섹션 간 맥락은 **구조**(섹션 배치·실습 정합성·무엇을 어디에 두나)와 **건조한 사실**로 실현된다. 프로즈로 그 맥락의 *중요성을 주장하지 않는다.* 맥락을 draft에 "세우려는" 순간 톤이 현란해진다.

| 지양(메타-강조) | 지향(사실만) |
|------|------|
| "이것이 이 실습의 **축·척추·핵심**이다" | 문장째 삭제, 사실만 남긴다 |
| "~를 보는 것이 이 실습의 **포인트/목적**이다" | "이 섹션은 X를 다룬다" 정도 담백한 예고만 |
| "여기서 X가 **강조된다/드러난다**" | X를 그냥 서술한다 |
| "A보다 **B가 핵심**이다" | 두 사실을 나란히 두고 경중 판단은 뺀다 |

**판별**: 이 문장이 *사실 서술*인가, *그 사실이 중요하다는 주장*인가. 후자면 삭제. thread의 '왜·축·회수'는 **plan(SSOT)에 살고, draft엔 사실만.**

### 6) 번역투 금지 — 한국어로 새로 쓴다

리서치가 영문이라 문장을 그대로 옮기면 직역투가 나온다. **영문에서 사실만 흡수하고 한국어로 새로 쓴다**(번역이 아니라 원작). 애매한 의역은 읽는 사람 판단이라 손대지 않되, 아래 세 가지는 철저히 지킨다.

| 유형 | 지양(직역) | 지향(한국어 원작) |
|------|------|------|
| **직역 동사** | 트래픽을 잇는다, 데이터가 흐른다, 대시보드를 얹는다, 맥락을 나른다, 마운트를 떠받친다 | 트래픽이 끊기지 않는다, 수집된다, 구성한다, 드러난다, 마운트에 쓴다 |
| **영문 어순**(후치 수식, 쉼표 삽입절) | SAS는 토큰이다, 시간과 권한을 제한한 / 계정은, 여러 서비스를 담는데, 경계다 | SAS는 시간과 권한을 제한한 토큰이다 / 계정은 여러 서비스를 담는 경계다 |
| **괄호 부연**(완결 절·문장) | 요청을 서명해 인증한다(SAS 서명에도 이 키가 쓰인다) | 요청을 서명해 인증한다. 이 키는 SAS 서명에도 쓰인다 |

- **직역 동사**는 데이터·트래픽을 물건이나 물처럼 다루는 의인화와 겹친다(2 리터럴의 연장). 단 `10~15분 걸린다`처럼 자연스러운 한국어까지 막는 blanket이 아니다. 판단이 필요하다.
- **영문 어순**: 한국어는 수식어가 명사 앞이다. 영문 관계절·도치를 쉼표로 그대로 끼우지 말고 어순을 재배치한다. grep으로 안 잡히니 읽으며 잡는다.
- **괄호는 금지가 아니다.** 병기(`Virtual Network(가상 네트워크)`), 짧은 값·용어(`(DefaultAzureCredential)`, `(점선)`), 이름 크로스레퍼런스(`"Gallery Blob 연동"`)는 유지한다. **완결된 절이나 문장**을 괄호에 넣지 말고 문장으로 푼다.

**뿌리**: 저 셋은 다 "영문을 문장 단위로 번역"해서 나온다. 리서치는 사실만 가져오고 draft는 한국어로 새로 쓴다.

## 영문 용어 표기

### 첫 등장 시
영문과 한글을 함께 표기: `Virtual Network (가상 네트워크)`

### 이후
영문만 사용: `Virtual Network`

### Azure Portal 메뉴
Portal UI 경로는 **한글만**(콘솔 표기 그대로). 별도 `(영문)` 병기를 붙이지 않는다. 루트는 `홈`. `IAM`·`SKU` 등 콘솔이 영문으로 쓰는 토큰은 유지. 영문 앵커는 개념부 첫 등장 병기에서 확보. (Ch04~ 적용, Ch01-03은 구 규약)
```
홈 > 가상 머신 > **만들기**
```

## 번역하지 않는 용어 목록

아래 용어는 한글 번역 없이 영문 그대로 사용한다.

## 문장부호 — 줄표와 가운뎃점 자제

국문은 영문만큼 문장부호를 촘촘히 쓰지 않는다. 부연이나 삽입은 쉼표, 괄호, 문장 재구성을 우선한다.

### 줄표(—)
줄표는 꼭 필요한 강조에만 절제해서 쓴다(남용하면 번역투로 읽힌다).
- 지양: `리소스를 담는 그릇 — 구독과 Resource Group — 을 만들었다`
- 지향: `리소스를 담는 그릇(구독과 Resource Group)을 만들었다`

### 가운뎃점(·)
나열을 `·`로 촘촘히 잇지 않는다. **3개 이상 나열은 쉼표(,)**로 푼다. `·`는 **밀접한 2항 고정 짝**(읽기·쓰기, 장·단점 등)이나 좁은 라벨에만 절제해서 쓴다.
- 지양: `Frontend IP·Backend Pool·Health Probe·Rule`, `Private Subnet·Bastion·NAT`
- 지향: `Frontend IP, Backend Pool, Health Probe, Rule`, `Private Subnet, Bastion, NAT`

## 숫자/단위

- 숫자는 아라비아 숫자: `8 GiB`, `3개`
- 포트: `8080`, `443`
- CIDR: `10.0.0.0/16`

비용 주의 섹션 없음.

기술적 주의사항은 본문에 자연스럽게 포함:
```
이 시점에서 {리소스}를 삭제하면 {영향}이 발생한다.
```
