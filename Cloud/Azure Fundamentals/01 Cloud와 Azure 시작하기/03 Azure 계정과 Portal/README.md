# 01 Cloud와 Azure 시작하기 / 03 Azure 계정과 Portal

Azure 계정 계층 구조를 이해하고, 무료 계정을 만들어 Portal과 Cloud Shell을 직접 다뤄보는 섹션.

## What you will learn

- Azure 계정 계층: Microsoft Account → Tenant → Subscription → Resource Group → Resource
- Resource Group의 역할: 리소스 묶음이자 수명 주기 단위
- Azure Portal 구성과 검색 기반 서비스 접근
- Cloud Shell: Storage 없이(ephemeral) 즉시 사용

## Examples

- `lab01` → Azure 무료 계정 생성, Portal 메뉴 탐색, Cloud Shell(ephemeral) 실행
