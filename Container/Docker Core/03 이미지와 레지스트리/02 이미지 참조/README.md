# 03 이미지와 레지스트리 / 02 이미지 참조

이미지를 가리키는 이름을 정리한다. 짧은 이름이 어떤 레지스트리의 어떤 이미지로 해석되는지 확인하고, 가리키는 대상이 바뀔 수 있는 태그와 바뀌지 않는 다이제스트를 구분한다. 이미지에 이름을 추가하는 방법과 이름이 push 대상을 정하는 관계를 다룬다.

## What you will learn

- 이미지 참조 형식 `[HOST[:PORT]/][NAMESPACE/]REPOSITORY[:TAG][@DIGEST]` 와 기본값(`docker.io`, `latest`), 공식 이미지의 `library` 네임스페이스
- `latest` 가 최신 이미지를 보장하지 않는 이유와 `latest` 가 없는 저장소의 다운로드 오류
- 태그와 다이제스트의 구분, 다이제스트 고정, 태그와 다이제스트를 함께 지정했을 때 다이제스트가 이미지를 결정하는 동작
- `docker image tag` 의 이름 추가 · 변경과 `Untagged`, 이미지 이름과 push 대상의 관계
