# 02 Azure IAM & Microsoft Entra ID / 01 Microsoft Entra ID 개요

Azure의 신원 관리 서비스 Microsoft Entra ID를 이해하고, "인증(누구인가)"과 "인가(무엇을 할 수 있나)"가 Azure에서 어떻게 나뉘는지를 잡는 이론 섹션.

## What you will learn

- Microsoft Entra ID의 역할: Tenant 수준의 신원 관리
- Tenant = Directory = 신원 제어 평면, Subscription과의 관계
- 인증(Authentication)과 인가(Authorization)의 구분
- AWS IAM과의 차이: Azure는 신원(Entra)과 리소스 권한(RBAC)을 분리
