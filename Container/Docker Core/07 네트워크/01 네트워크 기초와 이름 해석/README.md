# 07 네트워크 / 01 네트워크 기초와 이름 해석

컨테이너가 네트워크에 연결되는 방식과 내장 드라이버를 정리하고, 기본 bridge와 사용자 정의 bridge의 이름 해석 차이, 내장 DNS와 네트워크 별칭, 포트를 게시하지 않은 컨테이너 사이의 통신을 다룬다. 같은 절차를 두 네트워크에서 실행해 이름 접속과 IP 주소 변경의 결과를 대조한다.

## What you will learn

- 네트워크마다 할당되는 컨테이너의 IP 주소와 정지 · 재시작 후의 주소 변경
- 내장 드라이버(`bridge` · `host` · `none` · `overlay` · `ipvlan` · `macvlan`)의 용도와 기본 네트워크
- 기본 bridge와 사용자 정의 bridge의 차이(이름 통신, 이름 해석, 연결 대상), 네트워크마다 생성되는 서브넷과 브리지 인터페이스, 레거시 `--link` 의 지원 중단
- 내장 DNS 서버 `127.0.0.11`, 이름 해석의 범위, `--network-alias` 별칭, 컨테이너 이름과 호스트명
- 게시하지 않은 포트로 이루어지는 같은 네트워크의 통신과 포트 게시의 역할

## Examples

- `lab01` → 기본 bridge의 한계 (이름 접속 실패와 IP 접속, 호스트의 DNS 서버, 정지 · 재시작 후 IP 주소 변경)
- `lab02` → 사용자 정의 네트워크 (서브넷과 브리지 인터페이스, 이름 접속과 내장 DNS, IP 주소 변경 후 이름 접속 유지, 별칭과 호스트명, 게시하지 않은 포트의 접속 범위)
