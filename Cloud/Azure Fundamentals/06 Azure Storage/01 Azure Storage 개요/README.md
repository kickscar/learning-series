# 06 Azure Storage / 01 Azure Storage 개요

Azure Storage의 전체 지형 — Storage Account 아래 4개 서비스, 성능 계층, 중복성 옵션을 이해하는 이론 섹션.

## What you will learn

- Storage Account — 단일 네임스페이스에 Blob·Files·Queue·Table 4서비스
- 성능 — Standard(HDD, general-purpose v2) vs Premium(SSD, 특화 계정)
- 중복성 — LRS(데이터센터) → ZRS(Zone) → GRS(리전) → GZRS(Zone+리전). ZRS = 05.06 zone 분산의 스토리지판
- AWS 대응 — Blob↔S3, Files↔EFS/FSx, Queue↔SQS, Table↔DynamoDB
