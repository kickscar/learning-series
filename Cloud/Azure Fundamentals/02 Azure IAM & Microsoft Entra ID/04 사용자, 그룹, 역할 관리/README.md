# 02 Azure IAM & Microsoft Entra ID / 04 사용자, 그룹, 역할 관리

Entra ID의 신원 객체(사용자와 그룹)를 다루고, "역할"이 Azure에서 두 가지 다른 체계를 가리킨다는 것을 구분하는 섹션.

## What you will learn

- 사용자 유형: Member(내부)와 Guest(외부)
- 그룹: Security / Microsoft 365, Assigned / Dynamic 멤버십(P1)
- 역할의 두 체계: Entra 디렉터리 역할(신원) vs Azure RBAC 역할(리소스)
- 사용자·그룹 생성과, 역할 없이는 리소스가 보이지 않음(인증 ≠ 인가)
