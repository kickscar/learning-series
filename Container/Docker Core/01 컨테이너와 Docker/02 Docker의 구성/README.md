# 01 컨테이너와 Docker / 02 Docker의 구성

`docker` 명령을 입력하는 클라이언트와 명령을 실행하는 데몬의 구분을 명령 출력으로 확인한다. Docker Desktop과 Docker Engine의 설치 형태별 차이를 정리한다.

## What you will learn

- 클라이언트 · 데몬 · 레지스트리의 역할과 `docker version` · `docker info` 를 이용한 확인
- 데몬 미실행 시 동작과 연결 대상 데몬의 지정 (`docker context` · `DOCKER_HOST`)
- 데몬 소켓 접근 권한의 보안 의미
- Docker Desktop과 Docker Engine의 데몬 위치 차이와 확인 방법
