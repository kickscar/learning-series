# 01 컨테이너와 Docker / 01 컨테이너와 가상 머신

실행 환경의 차이에서 생기는 문제를 컨테이너 이미지가 어떻게 해결하는지 설명하고, 가상 머신과 비교해 컨테이너의 특징과 한계를 정리한다.

## What you will learn

- 컨테이너 이미지가 애플리케이션과 실행 환경을 하나의 패키지로 묶어 실행 환경 불일치를 해결하는 방식
- 읽기 전용 패키지인 이미지와 그 인스턴스인 컨테이너의 관계
- 호스트 커널을 공유하는 컨테이너와 운영체제 전체를 구동하는 가상 머신의 차이
- 가상 머신 위에서 컨테이너를 실행하는 병용 구성
- 컨테이너가 적합하지 않은 경우와 대응
